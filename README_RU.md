# SH1M Zapret — Android preview

Это исходный Android-проект-заготовка с русским интерфейсом для Android 8+ (целевой SDK 35 / Android 15).

## Честный статус
- Это **не готовый DPI bypass**.
- Кнопка подключения отключена намеренно: сетевой движок ещё не интегрирован.
- Windows-файлы `winws.exe`, `WinDivert.dll` и `.sys` из `zapret-discord-youtube 1.9.2` несовместимы с Android.
- Не выдавайте этот APK за рабочий обход Discord/YouTube.

## Как получить APK без Android Studio
1. Создайте новый пустой репозиторий GitHub в браузере телефона.
2. Загрузите содержимое этой папки в репозиторий, включая скрытую папку `.github`.
3. Откройте вкладку **Actions** и запустите **Build SH1M Zapret APK** (или дождитесь сборки после push).
4. Откройте завершённый запуск workflow и скачайте artifact `SH1M-Zapret-preview-apk`.
5. Внутри artifact находится `app-debug.apk`.

## Следующий обязательный этап
Для реального обхода нужно выбрать и интегрировать Android-совместимый движок обработки трафика (например, нативный userspace engine с Android TUN/VpnService), согласовать лицензии, адаптировать стратегии и протестировать на реальной сети. До этого подключение оставлено выключенным.

Требуются JDK 17, Android SDK API 35 и Gradle 8.9+:
